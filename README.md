# bare metal csv reader on stm32f412g-disco 
## based on https://github.com/aRkDev21/CsvReader/tree/main
# Features 
- rendering .csv on color TFT LCD
- navigating the table via joystick(5 buttons)
- touchscreen gestures handling && simple calibrating
- reading and navigating tables from memory
- read SD cards via FatFS and reading/saving data into .csv files
- connect usb-keybord via usb-otg (usb-host mode)
- debugging usb via vcom port
